# Code of Conduct

This project adopts the **[Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. The full text is published at the link above and is incorporated here by reference.

In short: be kind, be constructive, assume good faith. We want Sworde to be a welcoming space for contributors of every background and experience level.

## Scope

This Code of Conduct applies within all project spaces — the GitHub repository (issues, pull requests, discussions), and any public communication channels associated with Sworde.

## Reporting

If you experience or witness behaviour that goes against this Code, please report it privately to the maintainer:

- Open a [private security advisory](https://github.com/adityaswaroop823/sworde/security/advisories/new) (works for conduct reports too), or
- Email **aditya.swaroop@stage.in** with the subject line `Sworde Code of Conduct`.

Reports are confidential. The maintainer will acknowledge receipt within 72 hours and respond with next steps.

## Enforcement

Violations may result in temporary or permanent removal from project spaces, at the maintainer's discretion. Decisions follow the enforcement guidelines published in the Contributor Covenant linked above.
